How to read this site

One fictional company

Every piece is set at Tessaly Health, an invented nonprofit regional health system with about 4,000 staff. It isn’t modeled on any real employer.

Synthetic data, real methods

The data comes from a seeded generator anyone can rerun. Results show how a method works. They aren’t findings about real people.

AI-assisted code, checked by hand

I write the analysis with Claude and label the code that way. What I’m showing is the checking: reconciliations, read-backs and assumption tests.
