# Report rationalization worksheet (LIB-51)

**Purpose:** a worksheet for a reporting or learning operations lead to cut reporting sprawl, with stated criteria so each keep, merge or retire decision can be defended to the report's owner.

*Worked example at Tessaly Health, a fictional health system, on an invented report catalog.*

---

## Criteria, applied in order (the first that fits decides)

| # | Criterion | Decision |
|---|---|---|
| 1 | The catalog already marks it a duplicate | **Retire**; send users to the surviving report |
| 2 | No views in 90 days | **Retire** in 30 days unless the owner names a decision it supports |
| 3 | Same metric from the same source as another active report | **Merge** into the most-used one, with a view for each audience |
| 4 | Row-level extract | **Keep, restrict** to the analyst role; replace with a governed dataset |
| 5 | Fewer views than scheduled runs | **Review** with the owner; retire next quarter if unused |
| 6 | Otherwise | **Keep** |

Any surviving report on compliance, or read by executives, must use the governed metric definition and pass the pre-publication checks.

**Result:** 22 reports become 11, plus 1 under review. Five are retired and five are merged into the reports that absorb them. Four survivors now carry the governed-definition requirement.

The worksheet is generated by `analysis/rationalize.py`. Grouping reports into metric families is a judgment call, so the grouping is written in the script where it can be reviewed and changed.

## Why it's built this way

The criteria are ordered so the cheap, uncontroversial calls (duplicates, unused reports) are made before the ones that need a conversation. Merging keeps every audience's view but leaves one query behind it, which is the real point: two queries for one metric is how two numbers for one metric happen. Views per scheduled run, rather than raw views, keeps a quarterly report from being judged against a daily one. The 30-day objection window costs little and avoids retiring something a regulator asks for once a year.
